# KAREN V1 — clean rebuild

Black-chrome responsive HUD inspired by the user's approved design reference. All prices, probabilities, scores and performance numbers shown in the prototype are explicitly demo data. No live market feed, trade execution, or betting orders are enabled.

## Run

`npm start` (Node 20+). Health endpoint: `/health`.

## Railway

Deploy this GitHub repository with start command `npm start`; Railway supplies `PORT`.

## Roadmap

Real market feed adapters, authenticated accounts, verified settlement recorder, calibrated forecasts, sports provider integrations, voice and real ferrofluid animation. No owner-only or covert tracking features.
